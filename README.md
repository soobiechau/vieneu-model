# vieneu-model

Bản sao nguyên vẹn model giọng AI **VieNeu-TTS v3 Turbo (int8, ONNX)** của [pnnbao-ump](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo) (Apache-2.0)
và codec [MOSS-Audio-Tokenizer-Nano-ONNX](https://huggingface.co/OpenMOSS-Team/MOSS-Audio-Tokenizer-Nano-ONNX),
dùng riêng cho skill quảng cáo shop. Model nằm ở Releases (tạo tự động bằng GitHub Actions `tao-ban-sao-vieneu`).
Không sửa file model. Giấy phép: xem GIAY-PHEP.txt trong release.
